# 🧠 MLOps Hands-On Labs — Chameleon Cloud

This repository summarizes 8 hands-on labs from my MLOps coursework (Prof Fraida Fund at NYU, Spring 2025). It was conducted on [Chameleon Cloud](https://www.chameleoncloud.org/). 
Each week explored a different layer of production-grade ML systems — from infrastructure and training pipelines to serving, monitoring, and data systems.

*(Note: All materials here are my own summaries and screenshots; coursework notebooks are not shared to preserve academic integrity.)*

---

## 📚 Weekly Overview

| Week | Focus | Tools / Frameworks | Key Concepts & Takeaways |
|------|--------|--------------------|---------------------------|
| 1 | ML Systems Overview | — | Difference between prototypes vs production ML; key system components; intro to Chameleon Cloud |
| 2 | Cloud Computing | OpenStack (Horizon), Docker, Kubernetes | Provisioned VMs, networks, and containers; deployed simple K8s apps |
| 3 | DevOps & MLOps | Git, CI/CD, Terraform | Continuous deployment, infra as code; adapting DevOps for ML |
| 4 | Model Training at Scale | PyTorch DDP/FSDP, DeepSpeed, LoRA, QLoRA, LitGPT | Distributed and parameter-efficient training |
| 5 | Training Infrastructure | MLflow, Ray | Experiment tracking, training schedulers, system metrics |
| 6 | Model Serving | ONNX, TensorRT, OpenVINO, FastAPI, Triton | Serving optimization for cloud & edge; dynamic batching |
| 7 | Evaluation & Monitoring | GradCAM, Pytest | Offline/online evaluation, behavioral testing, explainability |
| 8 | Data Systems | MinIO, FUSE | Object storage, ETL pipelines, data lakehouse design |

---

## 💡 Highlights
- End-to-end exposure to MLOps workflows  
- Experimented with distributed and efficient model training  
- Deployed and optimized inference workloads using modern serving stacks  
- Explored evaluation, monitoring, and data management at scale
